# 2. Similaridade entre vetores

Agora que já sabemos que embeddings são vetores onde "distância = diferença de significado", falta a pergunta óbvia: **como a gente mede essa distância, de fato?**

## 2.1 Distância Euclidiana 

É a distância "de régua" entre dois pontos — a mesma fórmula que se aprende na escola:

$$d = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2 + ...}$$

Pensando nas coordenadas de novo: a distância euclidiana entre a cidade X e Y seria literalmente "quantos km em linha reta" separam as duas. Quanto menor a distância, mais parecidas.

**Problema**: Combina magnitude + direção, sendo assim

```
A [1, 4] = 'Eu gosto de pizza'
B [1, 12] = 'Eu desde criança sempre fui muito de comer pizza, gosto muito'
C [1, 4] = 'Não gosto de gatos'
```

Se atribuirmos valores de embeddings a cada palavra

```
Distância AB = 4
Distância AC = 2
```

Isso acontecendo pela magnitude que é uma força importante.

**Resumo**: Calcula a distância entre 2 vetores, quanto menor a distância mais parecidos eles são.

## 2.2 Similaridade de Cosseno 

Em vez de medir a distância entre os pontos, mede o **ângulo** entre os vetores — ignorando completamente o tamanho/magnitude deles.

$$\cos(\theta) = \frac{A \cdot B}{|A| \times |B|}$$

O resultado varia de -1 a 1:
- **1** → vetores apontam exatamente na mesma direção (extremamente similares)
- **0** → vetores perpendiculares (nada a ver um com o outro)
- **-1** → vetores apontam em direções opostas

**Por que isso importa**: dois vetores podem estar "longe" em distância euclidiana (magnitudes bem diferentes) mas apontando pra praticamente a mesma direção — ou seja, semanticamente muito parecidos. Cosseno captura isso; euclidiana não necessariamente.

```
"cachorro"          → [0.12, -0.44, 0.03, ..., 0.91]
"cachorro cachorro" → [0.24, -0.88, 0.06, ..., 1.82]  # dobrado, mas mesma "direção"
```

**Problema**: Como a magnitude é ignorada, frases com magnitudes diferentes são tratadas iguais

```
A = 'Eu gosto de pizza'
B = 'Eu amo muito pizza'
C = 'Eu sou apaixonado por pizza'
```

Nesse caso todas as frases apontam para a mesma direção, então aos olhos do coseno, todos são identicos, mas suas intensidades são diferentes, isso em embeddings poderiam ser um problema


**Resumo**: Calcula a similaridade entre 2 vetores, quanto mais perto de 1, mais parecido eles são.

## 2.3 Produto Interno (Dot Product)

$$A \cdot B = \sum a_i \times b_i$$

É literalmente o numerador da fórmula do cosseno, sem a normalização (sem dividir pela magnitude). 


**Fatos**: **se os vetores já estiverem normalizados** (magnitude = 1), produto interno e cosseno dão exatamente o mesmo resultado — só que produto interno é mais barato de calcular, o que importa muito quando há milhões de vetores num banco de dados vetorial.

É por isso que bancos vetoriais (FAISS, Pinecone, etc.) costumam normalizar os embeddings no momento da indexação e depois usar produto interno — matematicamente equivalente ao cosseno, mas mais rápido.

**Problema**: Assim como a Euclidiana, o produto interno combina direção + magnitude, voltamos com o problema da magnitude, porém aqui é ao contrario

```
A [1, 4] = 'Eu gosto de pizza'
B [1, 12] = 'Eu desde criança sempre fui muito proximo de gatos, gosto muito'
C [1, 4] = 'As vezes como pizza'
```

Se atribuirmos valores de embeddings a cada palavra

```
Dot Product (AB) = 4
Dot Product (AC) = 2
```

Pois aqui, vetores com magnitudes maiores tendem a dar valores maiores. 

**Resumo**: Calculamos a distância entre 2 vetores, quanto maior o valor, mais parecidos eles são (se normalizados)

## 2.4 Resumo prático

| Métrica | O que mede | Sensível à magnitude? | Uso comum | Range | Valor "idêntico" |
|---|---|---|---|---|---|
| Euclidiana | Distância "de régua" | Sim | Dados tabulares, clustering (k-means) | 0 → ∞ | 0 |
| Cosseno | Ângulo entre vetores | Não | Embeddings de texto (padrão da indústria) | -1 → 1 | 1 |
| Produto Interno | Ângulo + magnitude | Sim (a menos que normalizado) | Busca vetorial em escala (com vetores normalizados) | -∞ → ∞ | quanto maior, mais parecido |
